# Pothula Prashanth: Video Editor Portfolio

React + Vite. Edit `src/data.js` for all content.

- Hero background video: put `showreel.mp4` in `public/videos/` (under 10 MB) or set `youtubeBg` in `src/data.js`.
- Your photo: replace `public/images/prashanth.jpg`.
- Run: `npm install` then `npm run dev`
- Build: `npm run build`
